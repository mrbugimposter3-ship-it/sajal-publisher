Sajal Publisher – Privacy Policy

Last updated: October 22, 2026

Sajal Publisher is a personal script run by Rafeh Hussain on his own computer. It uses the YouTube Data API (scope https://www.googleapis.com/auth/youtube) only to manage playlists and video privacy settings on his own YouTube channel, سجلّ المغامر.

Data we access

The app accesses only the channel owner's own YouTube channel data (videos, playlists and their privacy status) needed to create playlists and change video visibility. It does not collect, request or process data from any other users.

Storage

The OAuth access token is stored only locally on the owner's computer. No data is uploaded to any server operated by the app.

Sharing

No data is sold, shared with or transferred to third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the local token file also removes the stored credentials.
